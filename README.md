# win97 · 壁纸匣

壁纸匣是一款开源的交互壁纸安装器，把 .tendies 动态交互壁纸装进 iPhone / iPad 的锁屏。

## 能做什么

- **逛目录**：内置壁纸目录，在线浏览、下载壁纸包。
- **导入**：从文件导入 .tendies 包，自动检查、去重。
- **安装**：装进锁屏，支持深景（人物压时钟）和陀螺仪视差。
- **导出**：把已装的壁纸导出来，再分享给别人。
- **管理**：批量导入、改名、换封面、换预览视频；管理员可以上传到目录。

没有广告，没有会员，不用注册账号。

## 怎么装上去的

App 在手机上开一个回环 VPN（流量不出手机），按 App 里的指引配对后，经系统服务把壁纸描述符写进 PosterBoard，再刷新，壁纸就出现在锁屏图库里。

- 直写：iOS 26.2–27.2 beta 2
- 备份还原：iOS 27
